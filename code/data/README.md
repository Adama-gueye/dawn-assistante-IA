## Corpus DAWN

Structure documentaire recommande pour le cadre sante mere-enfant.

- `pediatrie/` : documents cliniques pediatriques
- `gyneco_obstetrique/` : documents cliniques maternels
- `communs/` : references transversales

Ajoutez dans chaque dossier :
- cours PDF valides
- protocoles hospitaliers
- guides cliniques
- recommandations officielles
